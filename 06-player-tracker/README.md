# Player Tracker 🧭

A Minecraft Bedrock addon that shows nearby player count and closest player distance on the actionbar.

## How it works

- Hold a **compass** in your hand
- The actionbar shows:
  - **Players nearby** (within 100 blocks)
  - **Closest player** name and distance in blocks

## Installation

1. Import the behavior pack and resource pack into Minecraft Bedrock
2. Apply both packs to your world
3. Enable **Beta APIs** in Experiments (world settings)
