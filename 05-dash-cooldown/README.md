# Dash com Cooldown ⚡

A Minecraft Bedrock addon that adds a dash ability with a 5-second cooldown — an improvement over the first project.

## How it works

- **Use** (right-click) a **feather**
- You dash forward in the direction you're looking
- A **5-second cooldown** prevents spamming
- Actionbar shows cooldown status

## Installation

1. Import the behavior pack and resource pack into Minecraft Bedrock
2. Apply both packs to your world
3. Enable **Beta APIs** in Experiments (world settings)
