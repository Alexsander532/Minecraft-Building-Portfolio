# World Test

This folder is reserved for a **Minecraft Bedrock test world** used to validate the Dash Ability addon in-game.

---

## Purpose

Rather than requiring testers to manually set up a world, this folder can contain a pre-configured world export with:

- Both packs already applied (Behavior Pack + Resource Pack).
- **Beta APIs** enabled in world settings.
- A flat or open terrain for easy ability testing.

---

## How to Use a Test World

1. Export a world from Minecraft Bedrock as a `.mcworld` file.
2. Place the `.mcworld` file inside this folder.
3. To import it, double-click the `.mcworld` file — Minecraft will open and import it automatically.

---

## Current State

No world file is included yet. To test the addon manually:

1. Create a new world in Minecraft Bedrock.
2. Apply the **Behavior Pack** and **Resource Pack** from the `development_*_packs` folders.
3. Enable **Beta APIs** under **Experiments** in world settings.
4. Enter the world, pick up a stick, and right-click to trigger the dash.
