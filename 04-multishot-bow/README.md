# Multishot Bow 🏹

A Minecraft Bedrock addon that adds a custom multishot enchantment — every arrow shot from a bow spawns 2 extra arrows with spread.

## How it works

- Shoot an arrow with a **bow**
- 2 extra arrows spawn with slightly different directions
- Total of **3 arrows** per shot

## Installation

1. Import the behavior pack and resource pack into Minecraft Bedrock
2. Apply both packs to your world
3. Enable **Beta APIs** in Experiments (world settings)
