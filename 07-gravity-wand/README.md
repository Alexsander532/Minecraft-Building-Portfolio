# Gravity Wand 🌌

A Minecraft Bedrock addon that makes nearby mobs levitate when using a blaze rod as a wand.

## How it works

- **Use** (right-click) a **blaze rod**
- All mobs within **8 blocks** receive **Levitation** effect for **3 seconds**
- Actionbar shows how many mobs were affected

## Installation

1. Import the behavior pack and resource pack into Minecraft Bedrock
2. Apply both packs to your world
3. Enable **Beta APIs** in Experiments (world settings)
