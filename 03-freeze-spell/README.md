# Freeze Spell ❄️

A Minecraft Bedrock addon that freezes nearby mobs when the player uses a stick or blaze rod.

## How it works

- **Use** (right-click) a **stick** or **blaze rod**
- All mobs within **10 blocks** radius receive **Slowness 255** for **5 seconds**

## Installation

1. Import the behavior pack and resource pack into Minecraft Bedrock
2. Apply both packs to your world
3. Enable **Beta APIs** in Experiments (world settings)

## Usage

1. Hold a stick or blaze rod
2. Right-click (use the item)
3. Watch nearby mobs freeze!
